# Подсистема анализа угроз учебного заведения

Мини-SIEM для автоматического обнаружения брутфорс-атак на инфраструктуру учебного заведения. Разработан в рамках выпускной квалификационной работы по направлению 10.03.01 «Информационная безопасность».

## 🎯 Задача

Разработать систему, которая автоматически:
- собирает логи аутентификации с веб-сервера
- выявляет аномальную активность (многократные неудачные попытки входа)
- оповещает администратора ИБ в реальном времени
- сохраняет историю инцидентов для анализа

## 🛠 Что реализовано

- **Тестовый веб-стенд** — имитация страницы аутентификации СДО Moodle (Python `http.server`)
- **Сбор логов** — Filebeat + Logstash, нормализация событий
- **Хранение** — Elasticsearch (централизованное хранилище логов)
- **Детекция** — Python-модуль анализа событий аутентификации
- **Правило детектирования** — >10 неудачных попыток входа с одного IP за минуту
- **Алертинг** — Telegram Bot API (с прокси, т.к. Telegram заблокирован в РФ)
- **База инцидентов** — SQLite (`alerts.db`)
- **Визуализация** — Kibana (дашборды, графики динамики атак)

## 🧰 Стек

```
Python 3.9+  |  Elasticsearch 8.11  |  Kibana 8.11
Logstash     |  Filebeat            |  SQLite
Docker       |  Telegram Bot API    |  PowerShell (имитация атаки)
```

## ⚙️ Как это работает

1. Логи с тестового веб-сервера собираются через **Filebeat**
2. **Python-скрипт** (`analyzer.py`) читает логи, парсит IP и статус HTTP-ответа через regex
3. При превышении порога (10 неудачных попыток) формируется **алерт**
4. Алерт уходит в **Telegram** и сохраняется в **SQLite**
5. **Kibana** строит графики по инцидентам в реальном времени
